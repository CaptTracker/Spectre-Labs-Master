# Spectre Factions 1.0.0 (NeoForge 1.21.1)

First public release.

**Requires:** Spectre Lib 1.1.0+.

## Added
- **Player factions:**
  - Leader, officer and member ranks.
  - Open or invite-only, with clickable invites.
  - A faction colour and a `[TAG]` in chat, the tab list and nameplates.
- **Reputation and relations:**
  - Four relations: Hostile, Neutral, Friendly and Allied, set by reputation from -1000 to 1000.
  - Reputation changes when you attack, kill or defend someone, and slowly drifts back toward neutral.
- **Diplomacy:** war, peace, alliances and breaking treaties, with proposals that expire.
- **Friendly-fire protection** between friendly and allied players.
- **NPC guard modes** for mods that use them: Passive, Defend, Guard and Aggressive.
- **NPC factions** that other mods can register, with reputation just like players.
- The **faction screen** (G key) and the `/faction` command (`/f` for short).
- A server config for all the numbers.
