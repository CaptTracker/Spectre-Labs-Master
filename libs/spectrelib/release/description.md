# Spectre Lib

**Shared code for the Spectre Labs mods on NeoForge 1.21.1.**

Spectre Lib adds nothing to the game by itself. Install it when a mod that needs it asks for it, such as **Spectre Factions** or **Ancient Warfare Reforged**.

## For players
- Put it in your `mods` folder next to the mods that need it, on both the client and the server.
- It doesn't add any items, blocks or settings.

## For developers
- **Registration helper:** a single place to register a mod's content, including creative tabs.
- **Resource-id helpers.**
- **Item stack utilities.**
